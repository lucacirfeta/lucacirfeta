### About me

Senior Software Engineer & Team Lead with 5+ years of experience in enterprise backend development. I lead a team of 7 developers with end-to-end ownership: architectural design, Agile delivery, CI/CD, infrastructure security, and direct client engagement.

In parallel, I run an independent research line applying self-supervised vision transformers to LIGO gravitational-wave detector data — a series of sole-author arXiv preprints tracing an unsupervised anomaly-detection pipeline (DANTE) from its first architectural limitation to a full stress-test reanalysis of the O4a observing run.

- 🔭 **Currently working on:** microservices in **Java 17/21 + Spring Boot** (hexagonal architecture, SOLID), event-driven integration with **Kafka & AsyncAPI**, and lightweight components in **Node.js/TypeScript**
- 🔐 **Security & deployment:** mTLS, JWT/OAuth2, AWS Vault, ArgoCD (GitOps), GitHub Actions
- 🌊 **Researching:** unsupervised glitch detection in LIGO O4a strain data with frozen DINOv2 patch embeddings, Top-k multiple-instance scoring, and block-bootstrap threshold calibration
- 🤖 **Exploring:** AI-assisted engineering workflows (GitHub Copilot, Claude, Amazon Q Developer) — including agent config design for the team

### 🚀 Featured projects

**[DANTE / gravi-signal-ml](https://github.com/lucacirfeta/dante-gravi-signal-ml)** — Research, independent
Unsupervised anomaly detection for LIGO O4a strain data. Frozen DINOv2 (ViT-S/14, register tokens) patch embeddings, Top-k multiple-instance scoring against a vector-quantized reference index, and detector-specific thresholds calibrated by block-bootstrap — built to catch short-duration glitches that global (CLS-token) pooling architecturally averages away.
`Python` `PyTorch` `DINOv2` `Top-k MIL` `Block-bootstrap`

**[re-wine](https://github.com/lucacirfeta/re-wine)** — Personal project
An Android app to manage a personal wine cellar, with barcode scanning via the Open Food Facts API. Built to track and rediscover Italian regional wines (Barolo, Barbaresco, Nebbiolo).
`Flutter` `Riverpod` `SQLite` `GoRouter`
